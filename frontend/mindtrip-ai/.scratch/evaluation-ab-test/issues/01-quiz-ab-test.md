# 测评题量 A/B 对比

Status: needs-triage
Type: research

## 背景

8/3 产品讨论结论：测评不该在「8 题 vs 100 题」上二选一，应走「快测进门槛 + 行程约束 + 行为持续校准 + 深度卡增值」分层采集。已落地：11 题（8 快测 + 3 约束）、动线编辑行为记录、约束适配。尚未验证分层方案的实际效果。

## 任务

- 设计对比实验：8 题快测 vs 11 题分层 vs 双层（含深度卡）三组
- 指标：完成率、画像区分度（推荐结果多样性）、归途后满意度打分
- demo 内埋点方案（现有 session 数据可支撑部分指标）
- 出结论后再决定是否调整题量与流程

## 验收

一份可执行的对比方案 + 埋点清单；结论待实验数据。
