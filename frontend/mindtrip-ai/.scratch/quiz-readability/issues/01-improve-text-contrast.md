# 测评页题目文本可读性

Status: resolved
Type: task

## 背景

用户反馈测评页「文本框视觉效果很差，看不清文字」。塔罗底图调亮（opacity 0.88 + 蒙版 0.42–0.62）后，题目卡片 `rgba(46,38,28,0.55)` 半透明背景与浅金文字的对比度仍不足，选项按钮 `rgba(250,246,240,0.07)` 底 + 浅色描边在深底上发灰。

## 任务

- 加深题目卡片底色（如 `rgba(36,29,20,0.82)` 或实底 + 圆角 + 细描边），保证题干清楚
- 提亮题干与选项文字（`#F5EDDE` 向上调，如 `#FFF8EE`），选项描边加粗至可辨识
- 顺带检查行程约束分节提示条、上一题/下一题按钮的对比度
- 保留塔罗底图可见度，不退回全黑

## 验收

深棕塔罗底图上，题干、选项、按钮一眼可读，无文字发灰感；底图星纹仍隐约可见。
