# 01 · 全局导航栏 + 探索页城市光点位置修复

Status: resolved

## 背景
用户走 8 步旅程时反馈两个问题：
1. 页面间没有导航栏，只能靠页面内按钮跳转
2. 探索世界页里城市光点在地图上的标记位置与实际相差甚远

## 根因
- 导航：`_head.ejs` 只有居中 logo，无导航链接
- 地图：城市光点用 `position:absolute` 放在 SVG **外层**容器上，坐标用未缩放的 520×460 像素系——SVG 随容器缩放时（480px 容器实际缩到 ~92%）光点不缩放，越往右下偏差越大；且投影为等距圆柱（无纬度修正），形状观感与主流电子地图不符

## 修复
1. `_head.ejs` + `style.css`：顶部改 sticky 深棕半透明顶栏（blur），左 logo + 右 4 链接（首页/心灵测评/探索世界/我的画像），当前页 pill 高亮
2. `_foot.ejs`：pathname → 导航高亮映射（/scene、/route 归探索世界；/return 归我的画像；/consent 归测评）
3. `explore.ejs`：投影改 **Web 墨卡托**（纬度对数变换，版图与光点共用同一 proj）；光点从外层 div 移入 **SVG 内部 `<g>`**（circle 光晕 + circle 实点 + text 标签，同坐标系随版图同步缩放），点击/提示/脉动保留，文字用 paint-order stroke 描边防被版图线条干扰

## 验证
- 5 城墨卡托坐标相对位置与真实地理一致（大理最西南→成都→景德镇→杭州→苏州最东，经度/纬度排序正确）
- /、/quiz、/explore(带会话) 均渲染 app-nav；/explore 无会话 302→/quiz（既有设计）
