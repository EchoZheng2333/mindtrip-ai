# 心旅 AI（MindTrip AI）

心理-美学评测 × 文旅场景匹配推荐系统：用户通过情境测评得到人格画像，系统据此匹配城市人文场景、生成可编辑的心旅动线，并在旅途中持续校准。领域文档约定见 `docs/agents/domain.md`。

## Language

**心旅 AI（MindTrip AI）**:
把心理测评和文旅推荐结合的产品，核心是「人格 × 场景调性」匹配。
_Avoid_: 旅行助手、攻略 App

**情境快测**:
出发前必答的 8 道情境选择题，选项是生活场景（山间独处、逛夜市、拉坯手作），不暴露心理学术语，用于生成四维画像。
_Avoid_: 心理测试、性格测试

**行程约束**:
出发前补答的 3 项硬性安排（同行人 / 预算 / 出行目的），与人格一起参与匹配，决定动线的硬条件。
_Avoid_: 问卷、附加题

**四维画像**:
由快测与约束得出的「审美—情绪—社交—节奏」四维评分。
_Avoid_: 人格分数、维度分

**人格标签（人格卡）**:
画像的具象化呈现：人格名称 + 诗意标签 + 四维雷达 + 心灵指数。当前有 6 类人格。
_Avoid_: 性格类型

**心灵指数**:
一个 0–98 的量表，出发前由画像算出，旅途中被停留时长、快评与动线编辑行为持续校准，归途生成最终值。
_Avoid_: 评分、得分

**分层采集**:
数据策略：快测进门槛 + 行程约束 + 途中行为校准（打卡/停留/快评/动线编辑）+ 可选深度卡，数据随旅程持续累积。
_Avoid_: 加题、问卷扩充

**隐式问卷**:
用户在动线编辑器里的拖拽换序、场景替换行为，被记录并反哺画像，是比自陈更可信的行为数据。
_Avoid_: 行为追踪、埋点

**场景**:
一座城市里被收录的真实游玩点位（POI），含坐标、营业时间、人文调性（静谧/烟火/手作/夜色）、价格档位。
_Avoid_: 景点、地点

**场景人文调性**:
场景在「静谧/烟火/手作/夜色」等维度上的气质标签，是「人格 × 场景」匹配的另一端，属 L3 自建数据（护城河）。
_Avoid_: 分类、类型

**城市**:
文旅服务的最小运营单元，拥有一套场景库与动线库。当前仅 `jingdezhen` 开放；苏州/杭州/大理/成都为占位城市（未开放）。
_Avoid_: 目的地、站点

**开放城市**:
`status: open` 的城市，可进入其城市游玩路线页。
_Avoid_: 已上线城市

**心旅动线**:
系统为一位用户生成的可编辑多日行程（1–5 日），支持拖拽换序、从备选场景池替换。
_Avoid_: 行程单、路线

**备选场景池**:
动线编辑器旁的可替换场景列表，按行程约束的契合分排序并附推荐理由。
_Avoid_: 候选列表

**探索世界页**:
画像页之后、城市路线页之前的地图选城页面（中国简化版图，开放城市可点）。
_Avoid_: 地图页、选择城市页

**加载页 / 首页 / 隐私授权页 / 测评页 / 画像生成页 / 画像页 / 探索世界页 / 城市路线页**:
前端 8 步旅程的页面名（按序）：拼图加载 → 项目介绍 → 知情同意 → 情境测评 → 画像生成缓冲 → 画像结果 → 选城 → 城市动线。
_Avoid_: 各自混用的临时叫法（如"结果页"需说画像页）
