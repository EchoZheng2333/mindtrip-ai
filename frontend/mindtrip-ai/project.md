## 一、项目概述

### 1.1 项目简介

**「心旅 AI (MindTrip AI)」** 是一款将"心理-美学算法测评"与"人文调性文旅场景"深度匹配的定制化 AI 大模型推荐系统，致力于打造 **"AI 智能版心灵点评"**。

传统文旅推荐平台（如大众点评、携程、小红书）依赖"竞价排名""硬性消费指标"或"海量碎片化攻略"，导致用户深陷"选择过载"与"审美同质化"的困境——翻了一小时攻略却更迷茫，最终选择了一家评分高但毫无灵魂的"网红店"。**心旅 AI 的诞生，就是要打破这一困局。**

我们以景德镇为首发试点城市，跑通"AI + 独立手作/独立审美"的完整商业闭环。中期逐步向大理、丽江、阿那亚、成都、西安等具有"强人文调性、高情绪价值、多独立长尾商家"的特色城市快速复制。**最终构建一个全国首创的"心灵美学文旅数字生态"，让每一次出行都成为一场与内心的深度对话。**

### 1.2 项目亮点

| 维度 | 创新点 | 差异化价值 |
|------|--------|-----------|
| **技术** | 心理-美学双引擎匹配算法 + 多模态情感计算 + LLM 动态路径规划 | 实现"情绪+审美"双维精准可量化的精神共鸣推荐 |
| **场景** | 以景德镇为首发，覆盖非遗制瓷、独立买手店、隐世景区 | 切入高客单价、高情绪价值的深度文旅细分赛道 |
| **模式** | 轻量级微信小程序切入，B 端长尾商户平权赋能 + C 端沉浸式交互测评闭环 | 降低获客成本，打造双边网络效应与数据飞轮 |
| **价值** | 响应"乡村振兴、传统文化传承、实体经济数字化转型"国家战略 | 兼具商业效益与社会效益的可持续商业模式 |

## 二、市场痛点与机会

### 2.1 传统文旅推荐的三大困境

当前文旅推荐市场存在根深蒂固的结构性问题，主要体现在三个方面：

| 痛点 | 表现 | 数据佐证 |
|------|------|----------|
| **选择过载** | 用户在小红书/携程/大众点评筛选超 30 分钟仍无法决策，碎片化攻略加剧焦虑而非解决需求 | 调研显示 68% 的年轻旅行者因攻略过多产生焦虑，42% 最终放弃深度规划、随缘出行 |
| **审美同质化** | 竞价排名导致千人一面，搜索结果被商业化填充，真正有调性的小店被算法淹没 | 长尾独立商家曝光率不足头部商户的 5%，优质内容的可见性严重不公 |
| **情感缺失** | 推荐逻辑依赖"人均消费""评分星级"等硬性指标，缺乏情绪价值和个性化温度 | 73% 用户表示愿意为"更懂自己的定制体验"支付 20-50% 的溢价 |

**更深层的洞察**：现代年轻人的旅行动机正在发生根本性转变——从"我去过哪里"到"我遇见了怎样的自己"。旅行不再是消费行为的堆砌，而是一种 **自我探索和精神滋养的方式**。然而现有平台无法理解这一需求层次。

### 2.2 市场机会

心旅 AI 精准卡位三大高增长赛道的交汇点：

| 赛道 | 市场数据 | 增长驱动 |
|------|---------|---------|
| **文旅市场** | 2024 年国内旅游总花费超 6 万亿元，其中定制游/深度游市场年增长率超 25% | 后疫情时代"报复性出游"转向"品质性出游"，消费者更愿为深度体验买单 |
| **心理与性格测评市场** | 全球心理健康 APP 市场规模 2027 年预计达 76 亿美元，中国性格测试用户超 3 亿 | Z 世代"自我探索"需求爆发，MBTI 等性格测试社交话题热度持续攀升 |
| **手工/非遗体验经济** | 景德镇陶溪川年客流量超 500 万人次，非遗传习类体验消费年增 40%+ | 国潮复兴与文化自信提升，"亲手做一件陶瓷"成为高净值旅行者的刚需体验 |
| **AI 个性化推荐赛道** | AI 驱动的推荐系统市场 2032 年预计突破 500 亿美元 | 大模型技术成熟使"千人千面×千时千景"的实时动态规划成为可能 |

**心旅 AI 站在三大风口交汇点：心理健康 × 文旅消费 × AI 大模型。**

## 三、核心产品形态

### 3.1 用户旅程三步曲

心旅 AI 的产品体验围绕"认识自己 → 遇见风景 → 收获共鸣"这一核心叙事展开，共分为三个关键步骤。

#### 第一步：灵魂美学测评——一场由 AI 引导的"心灵冥想"（Mental & Aesthetic Meditation）

用户进入微信小程序，开启一场 **兼具视觉沉浸感与趣味交互的"心灵冥想"**。测评不再是传统"问答"，而是一次由 AI 引导的多感官交互艺术体验（约 8-12 题，5-8 分钟）。

**沉浸式交互设计：**

- **动态视觉叙事**：测评界面采用流体交互技术，用户指尖滑过屏幕时会带动色彩涟漪。当用户面对"以下哪组器皿的质感让你最平静？"时，6 组实拍陶瓷照片会以慢速叠化方式呈现，背景画面会根据用户的停留时间和选择倾向产生微妙的色彩渐变——仿佛水面的涟漪扩散，让用户在下意识层面完成"美学直觉"的筛选。

- **自适应音乐频率**：AI 根据用户每一步的选择，实时调整背景音的频率和配器。例如，若用户连续选择了"侘寂粗粝"风格的照片，背景音乐会从轻松的吉他拨弦渐变为低频的陶罐共鸣声和大自然白噪音，帮助用户进入更深层的放松状态，从而做出更接近本心的选择。每一步选择，听觉反馈都在暗示用户："我在倾听你。"

- **动态题枝引擎**：测评不是固定的题序。当用户在前 3 题展现出明显的"疗愈沉浸"倾向时，后 5 题会自动转向"独处体验偏好""自然空间敏感度"等深层维度，舍弃与其无关的"社交派对"类题目，使测评效率最高且用户不会感到疲惫。

**五类核心试题范式：**

| 试题类型 | 示例 | 测量维度 |
|---------|------|---------|
| 图像直觉选择 | "以下哪组器皿的质感让你最平静？"——精选 6 组涵盖侘寂粗粝/青花雅致/现代极简/古怪可爱等风格 | 美学光谱定位 |
| 色彩情绪映射 | "选出最能代表你此刻旅行心情的一组色块"——6 组精心调制的低饱和/高饱和/暖调/冷调色块 | 情绪状态指数 |
| 场景心理投射 | "偶遇一间深夜营业的隐世茶室，你会？A.径直推门而入 B.驻足观望 C.拍照离开 D.约朋友改天再来" | 行为倾向分类 |
| 行为偏好解码 | "规划自由时间时，你更倾向？A.随性漫步 B.提前查好路线 C.看当地人推荐" | 决策风格识别 |
| 价值观映射 | "旅行中你最珍视的是？A.拍到好照片 B.与当地人交流 C.独处时光 D.独特的故事体验" | 深层动机解析 |

**输出结果**：算法结合大五人格 + 荣格心理类型 + 美学偏好模型 + 实时情绪监测，建立三维用户画像：

- **"美学光谱"**：精确到用户在"侘寂极简 → 复古重器 → 中式美学 → 现代设计 → 古怪可爱 → 波普潮流"光谱上的定位点
- **"行为心理画像"**：独行探索型 / 社交共鸣型 / 亲子陪伴型 / 疗愈沉浸型 / 文艺创作型 / 美食猎奇型，并附带置信度评分
- **"情绪状态指数"**：当前情绪能量水平（从"枯竭"到"充盈"）+ 渴望的旅行节奏（悠闲慢游 / 紧凑充实 / 随性切换）

#### 第二步：心流日程动态生成（Dynamic Itinerary Engine）

AI 引擎在 **3 秒内**完成四维匹配与动态路径规划：

```
用户画像(美学+心理+情绪) + 时间节点(1/2/3/5天) + 出行同伴(独行/情侣/亲子/好友) + 实时预算
                            ↓
            [景德镇 500+ 优质长尾商户数据库 × 细粒度调性知识图谱]
                            ↓
        → 每日最优路径规划（空间连贯性+时间合理性+情绪节奏感）
        → 每个节点 3 选 1 方案（用户可根据偏好微调）
        → 天气/交通/营业时间实时适配
```

**算法亮点**：
- **空间聚类优化**：将推荐点按地理集群分组，减少无效穿行，同一条路线上的店铺调性高度一致，确保"走一路、爱一路"
- **情绪节奏曲线**：根据用户画像控制行程"呼吸节奏"——高社交能量的推荐点之间插入静谧独处空间，避免"审美疲劳"。例如，对"疗愈沉浸型"用户，算法会优先安排"上午独处手作体验 → 中午静谧茶室午餐 → 下午深度游览 → 傍晚落日漫步"的舒缓节奏
- **动态备选机制**：每个时间段提供 3 个同调性备选，用户可一键替换，既保持定制感又保留选择弹性

#### 第三步：共鸣细节呈现——"跨时空对话"式心动推荐（Resonant Details with Time-Travel Narrative）

这是心旅 AI 最具温度感的设计。路线中的每一个推荐点，都配有 **AI 独家撰写的"心动推荐语"**——不是冷冰冰的"人均消费 ¥120"，而是充满场景感、人物故事与历史纵深感的叙事：

> *"这家藏在弄堂深处的独立柴窑工作室，主人家姓周，养了一只圆滚滚的橘猫叫'泥团'。六十平的院子里堆满了柴烧的器皿，带着粗粝的泥土感与手作的温润余温。我们推荐它，是因为您在测试中展现了强烈的'渴望自然治愈'特质——这里的光线会在午后三点穿透天窗，正好落在拉坯台上。* **你知道吗？你在这里触摸到的泥土，与千年前的宋代匠人同温。** 景德镇的柴烧工艺自宋真宗时期便已名扬天下，而这一刻，你与千年前的匠人呼吸着同一座窑炉的烟火气。"*

**推荐语的"四层叙事"结构：**

| 叙事层 | 功能 | 示例 |
|--------|------|------|
| **环境描写** | 构建空间感与感官氛围 | "六十平的院子，午后光线穿透天窗落在拉坯台上" |
| **人物故事** | 建立人与人的情感连接 | "主人家姓周，养了一只圆滚滚的橘猫叫'泥团'" |
| **调性匹配理由** | 明确说出"为什么推荐给你" | "您在测试中展现了强烈的'渴望自然治愈'特质" |
| **跨时空注脚** | 赋予体验历史厚度与文化共鸣 | "你触摸的泥土与宋代匠人同温" |

## 四、核心技术架构：解码"精神共鸣"的量化引擎

### 4.1 心理-美学双引擎匹配系统

心旅 AI 的核心技术壁垒在于 **将"精神共鸣"这一主观体验转化为可量化、可匹配的算法信号**。这需要心理模型与美学模型的双向深度耦合。

#### 引擎一：心理学模型深度映射层

我们将经典心理学理论转化为可执行的推荐指令，构建了一条"心理维度 → 算法参数 → 推荐策略"的完整链路：

| 心理学模型 | 测量维度 | 算法参数转化 | 推荐策略映射 |
|-----------|---------|-------------|-------------|
| **大五人格** | 开放性/尽责性/外向性/宜人性/神经质 | 各维度的百分位评分（0-100） | 开放性高→推荐实验性/小众体验；神经质低→推荐安静独处空间 |
| **荣格心理原型** | 天真者/探险家/智者/创造者/统治者等12原型 | 用户在原型的加权匹配得分 | 探险家原型→推荐"隐藏菜单"和"未开发路线"；智者原型→推荐深度讲解和工艺溯源 |
| **情绪状态指数** | 能量水平(枯竭→充盈)+ 渴望节奏(慢→快) | 连续标量值（0.0-1.0） | 低能量+慢节奏→推荐疗愈系行程；高能量+快节奏→推荐密集探索行程 |

**关键示例**：对于"疗愈沉浸型"用户（大五人格中神经质偏高、开放性偏高，荣格原型中"智者"和"天真者"权重高），算法在路径规划时会自动调高以下权重参数：

```
私密性权重: 提升至 0.85（默认 0.5）→ 优选巷弄深处、非临街的秘境空间
自然采光权重: 提升至 0.75 → 优先推荐带天窗、庭院、落地窗的场所
人流密度阈值: 降至 0.3（默认 0.6）→ 自动过滤客流高峰时段和人流密集点位
声音环境偏好: 静音级 → 推荐仅有自然音（柴烧噼啪声、流水声）的工作室
空间节奏: 慢速 → 每站建议停留时间 60-90 分钟，而非传统的 30-40 分钟
```

#### 引擎二：多模态美学风格解析层

传统推荐系统仅处理文本数据，心旅 AI 引入了 **多模态情感计算**，对视觉、文本、空间信息进行联合解析，实现美学偏好的精准量化。

**（一）计算机视觉（CV）——图像美学特征提取**

系统自动解析商户上传的照片（实拍场景图、器物特写、空间环境图），提取以下美学特征并自动生成标签：

| 视觉维度 | 解析算法 | 提取标签示例 |
|---------|---------|-------------|
| **色彩分析** | HSV 色彩空间聚类 + 色温检测 | 高饱和撞色 / 低饱和大地色 / 冷调蓝白系 / 暖调橙黄系 / 黑白极简 |
| **构图风格** | 对称性检测 + 留白比计算 + 线条密度分析 | 极简留白 / 繁复装饰 / 几何规则 / 自然随意 / 堆叠丰盈 |
| **材质纹理** | 局部二值模式(LBP) + 纹理粗糙度分析 | 粗粝陶土 / 光滑釉面 / 亚光磨砂 / 编织肌理 / 金属光泽 |
| **光线氛围** | 直方图分布 + 光源方向检测 | 暖黄灯光 / 自然天光 / 硬朗顶光 / 柔和散射 / 昏暗烛光 |
| **空间感知** | 深度估计 + 空旷比计算 | 宽敞开放 / 紧凑温馨 / 层高挑空 / 庭院渗透 / 巷弄纵深 |

**CV 标签与用户美学光谱的匹配逻辑**：

```
用户美学光谱定位点：[侘寂极简 ———●——— 波普潮流]
                     偏好：低饱和、粗粝质感、自然光
                            ↓ 余弦相似度匹配
商户 A 图像特征：大地色系(0.92) + 粗粝质感(0.88) + 自然天光(0.85)
                      → 美学匹配度: 91%
商户 B 图像特征：高饱和撞色(0.90) + 光滑釉面(0.85) + 暖黄灯光(0.78)
                      → 美学匹配度: 37%
```

这意味着即使商户不会写任何文字描述，只要上传了几张店铺实拍图，系统就能自动解码其美学调性并找到最契合的用户。

**（二）LLM 评论语义转标签——非结构化文本的结构化提取**

利用大语言模型对商户的 UGC 评论进行细粒度情感分析与调性标签抽取：

> 原始评论："这家店氛围很好，老板很温柔，器皿很有质感，坐在院子里喝了一下午茶，感觉整个人都被治愈了。"

> LLM 提取的结构化标签：
> ```
> {
>   "氛围标签": ["安静治愈", "庭院惬意", "慢时光"],
>   "审美风格": ["侘寂风", "自然系"],
>   "适合人群": ["独行疗愈型", "文艺创作型"],
>   "关键词": ["温柔店主", "庭院茶歇", "治愈体验"],
>   "情绪评分": {"治愈感": 0.95, "放松感": 0.88, "社交欲": 0.35},
>   "最佳场景": ["午后独处", "雨天发呆", "轻阅读"]
> }
> ```

此技术使得心旅 AI 进入新城市时，可在 **2 周内完成 300+ 商户的自动化标签标注**，人工仅需做 10% 的抽样校验，大幅降低了规模化扩张的边际成本。

### 5.2 长尾商户平权机制——心旅的"流量正义"

**核心洞察**：大平台的"竞价排名"机制对长尾商户形成系统性生态剥削——越有调性的小店越无力支付高昂的广告费用，从而被算法彻底淹没。这不仅是不公平，更是对文旅多样性的扼杀。

**心旅解法**：我们建立了一套 **"以调性论英雄"** 的流量分配机制，包含三大核心设计：

**一、零门槛智能标注工具——"商户数字助理"**

商户入驻后，平台提供专属的 **AI 调性诊断**。即使是一个不会写文案、不会拍短视频的非遗老匠人，也只需完成以下几步：

1. **上传 5-8 张店面/作品实拍图** → CV 系统自动解析美学特征（色彩、质感、光线、空间），生成初始标签
2. **回答 3 个简单问题**（"你的客人来你这通常是什么心情？""你觉得自己最擅长的工艺是什么？"）→ LLM 自动生成"店铺故事线"
3. **AI 输出"调性诊断书"**：包含店铺的美学定位、目标用户画像、推荐话术建议
4. **一键生成"故事海报"**：AI 将标签组合为一套带有温度感的社交媒体素材（配图+推荐语），老匠人可以一键转发到朋友圈

**二、调性权数与惊喜流量权重**

算法不仅看用户画像与商户标签的匹配度，还引入两项平权设计：

```
最终推荐得分 = 匹配度(0.6) + 调性独特性(0.2) + 惊喜流量权重(0.2)

其中：
· 匹配度：用户画像与商户标签的余弦相似度
· 调性独特性：商户美学标签在数据库中的稀有度（越独特权重越高）
· 惊喜流量权重：给予新入驻商户和边远小店 3 个月的流量扶持期
```

这意味着：**一家藏在三宝村深处的柴窑匠人，只要其"侘寂柴烧"标签足够独特，就能获得比商业街网红店更高的推荐优先级**——算法主动为用户发掘"遗珠之憾"，而非让流量持续向头部集中。

**数据支撑**：景德镇陶溪川和雕塑瓷厂内，独立手作工作室占比超 70%，但在大众点评等平台的平均曝光排名低于 200 位——他们是"被埋没的宝藏"。心旅 AI 要做的，就是把这些宝藏一个个挖掘出来，送到懂得欣赏的人面前。
