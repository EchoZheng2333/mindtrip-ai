# 双轨语言：对外产品语言 vs 算法内部信号

心旅 AI 决定对外（用户可见）一律使用「四维画像—人格卡—心灵指数」的产品语言——情境快测不暴露任何心理学术语——而心理学模型（大五人格、荣格 12 原型、美学向量）仅作为算法内部信号保留在引擎中，两者建立映射。

背景：仓库内存在两代实现与两套语言。v1.2（EJS mainline）的四维语言（审美/情绪/社交/节奏 → 6 人格 → 心灵指数 0-98）已通过真实用户验证；商业计划书与 backend（FastAPI）则使用大五人格、荣格原型、美学光谱的心理学语言。若对外直接暴露心理学术语（"你的神经质维度 0.7"），产品失去温度、与已验证的 v1.2 冲突；若彻底丢弃心理学模型，则商业计划书的算法叙事与 backend 引擎失去存在意义。

选择：双轨。算法内部保留心理学模型作为匹配信号（商业计划书与评委语境仍可讲心理学故事），输出层映射为四维画像与心灵指数（产品 UI 不讲心理学名词）。

考虑过的替代：A. 完全以四维语言为准、丢弃心理学模型——损失商业计划书叙事与 backend 引擎价值；B. 完全以心理学语言为准——牺牲用户体验温度，且推翻已验证的 v1.2 语言。

后果：未来所有新功能必须走「内部信号 → 产品语言」的映射层；UI 文案禁止直接暴露心理学模型名词；backend 引擎作为算法层保留，其输出需转换为四维画像/心灵指数后呈现给用户。
