# 心灵足迹去 Web3 化

心旅 AI 决定"心灵足迹"为归途生成的轻量数字纪念卡（行程回顾 + 心灵指数 + 诗意札记），移除 backend module_5 中的钱包地址 mock 与 NFT 叙事。

背景：商业计划书阶段三曾设想 NFT 数字资产，backend module_5 实现了 wallet mock 与忠诚度折扣。演示版语境下，钱包/NFT 概念悬浮，且分散"心灵指数成长弧线"这条情感主叙事的焦点。

选择理由：demo 展示应聚焦情感弧线；纪念卡是天然分享点，比 NFT 更有真实感、更可落地。

后果：演示版不出现钱包/区块链字样；backend 的 MindPrint 保留为内部实现，输出收敛为纪念卡内容（美学 DNA、情绪曲线、叙事札记保留，钱包与折扣删除）。
