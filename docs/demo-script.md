# 心旅 AI · 5 分钟比赛演示脚本（v1.0）

> 目标：2026-10-17 · 演示版基于 EJS v1.2 mainline
> 一句话主张：**传统文旅软件推荐"消费坐标"，我们推荐"灵魂归属"。**
> 配合 `docs/demo-requirements.md` 的 6 屏节奏使用；演示前清空 `data/sessions/`。

## 一、演示环境准备（前一天）

- [ ] 启动服务：`cd frontend/mindtrip-ai && node server.js`，访问 http://localhost:3000
- [ ] 清空 `data/sessions/`（避免历史数据串场）
- [ ] 确认 `.env`：DeepSeek key（文案）+ AMAP_KEY（地图）+ AMAP_WEB_KEY（天气）均已配置
- [ ] 实测一次完整流程（测评→画像→动线→打卡→归途），确认 DeepSeek 文案正常生成

- [ ] 设备准备：外接屏幕/投屏、音量开启（测评页氛围音）、浏览器全屏无干扰
- [ ] 降级预案：若 DeepSeek/高德网络异常，确认降级路径（硬编码文案 / SVG 地图 / 天气隐藏）

## 二、演示流程（约 4 分 30 秒）

### 0. 开场白（30 秒）
> "选一座城，攻略刷了 40 篇，最后还是跟风打卡。旅行的意义不该是'去了哪'，而是'遇见了怎样的自己'。
> 心旅 AI——先测心灵，再定行程。它不推荐消费坐标，它推荐灵魂归属。"

**操作**：停在首页，不点任何按钮。

### 1. 首页 → 测评（15 秒）
> "8 道情境题，2 分钟。选项都是生活场景——山间独处、拉坯手作——没有一个心理学术语。"

**操作**：点击「开启你的自我探索之旅」，进入测评页。

### 2. 测评页 · 全视觉沉浸（60-90 秒）
> "测评是一场心灵冥想：背景光晕随选择改变色温，每个选择有器物轻叩般的音效——它在听你。"
> （答 3-4 题后）"系统在后台实时计算你的审美-情绪-社交-节奏四维画像，并匹配景德镇的场景调性。"

**操作**：边讲解边快速作答 11 题（8 快测 + 3 行程约束，选中即自动跳转）。最后展示"收集审美碎片"的粒子加载动画，进入画像页。

### 3. 画像页 · 人格卡（30 秒）
> "山间独行者——你的四维雷达和出发前心灵指数 85 分。注意看，指数不是固定值，它会在旅途中生长。"

**操作**：等雷达展开动画 + 指数滚动完成，点「开始探索世界」。

### 4. 探索世界（10 秒）
> "景德镇开放，其他城市正在点亮。我们以景德镇为首发样板，模式可复制到任何有人文调性的城市。"

**操作**：点击景德镇，进入动线页。

### 5. 动线页 · 数据诚意（60 秒）——全场重点
> "10 个真实场景，坐标全部实地校准——地图上每个点都可以点开，看到真实地址、营业时间、人流分布。
> 今天的天气也接入了实时数据。（指天气卡片）"
> "预算不是拍脑袋——按你的价格档位实时估算，人均 ¥xxx。（指预算卡）"
> "最重要的是：动线可以编辑。不喜欢就拖走，备选池里换一个，每一次调整都在优化你的画像。"

**操作**：
1. 点地图上 1-2 个 Marker 展示场景页（配图 + 诗意文案 + 人流分布图 + 打卡按钮）——点开御窑博物馆，展示 AI 配图和"为什么适合你"
2. 返回动线，拖拽一个卡片换位（或点上下箭头），展示"已自定义"徽标
3. 在场景页点「到达打卡」，展示停留计时

### 6. 归途 · 心灵足迹（30 秒）——收尾记忆点
> "旅程结束，系统生成一张只属于你的心灵足迹：指数从 85 长到 97，走过的每个场景都在卡上，AI 为这次旅程写了一段札记。一键保存，分享给下一个出发的人。"

**操作**：点「查看归途评估」，展示纪念卡；点「保存这张心灵足迹」，展示导出图片；最后停在卡片上。

### 7. 收尾（15 秒）
> "心旅 AI——让每一段旅程，都与内心同频共振。谢谢。"

## 三、评委 Q&A 口径

### Q1: 你们和携程/小红书/大众点评的区别？
- 推荐逻辑不同：它们按销量/竞价，我们按"人格 × 场景调性"匹配——4 个用户进同一座城，会拿到 4 条不同的动线；
- 数据维度不同：我们是多模态（测评画像 + 行为校准 + 场景人文调性标签），它们只有文本+位置；
- 商户生态不同：我们给长尾手作/非遗匠人"以调性论英雄"的平权曝光，而不是流量向头部集中。

### Q2: 匹配算法怎么实现的？心理学依据是什么？
- 双轨设计：用户侧不暴露心理学术语（体验友好），算法内部用经典心理学模型——大五人格、荣格原型、情绪状态指数映射为路由参数（私密性/节奏/人流阈值等），再与场景美学向量做余弦匹配；
- 数据飞轮：动线编辑、停留时长、快评会反哺画像（隐式问卷），越用越准。

### Q3: 景德镇的 10 个场景数据怎么来的？
- 真实 POI + 实地校准坐标（最高修正 3.4km 偏移）+ 营业时间/人流分布结构化；
- 场景人文调性标签是我们的 L3 自建数据，是护城河；进入新城市 2 周可完成 300+ 商户标注（LLM 评论转标签 + 10% 人工抽验）。

### Q4: 商业化路径？
- B 端：小微商户年费（199-299 元/年）+ AI 调性诊断书 + 故事海报自动生成；
- C 端：深度体验代订返佣（8-15%）、非遗课程预约佣金；
- 远期：买手制电商分佣 + 联名文创 + 定制行程包；心灵足迹作为复购与分享裂变点。

### Q5: 隐私与合规？
- 知情同意前置（首页折叠 + 测评页提示）；测评与旅行数据仅用于生成本次推荐，行程结束即清除；不做第三方出售。

### Q6: 多城市怎么复制？
- 核心算法与商户数据库完全分离（模块化）；城市 = 场景库 + 动线库的运营单元；当前景德镇 open，大理/苏州/杭州/成都为占位，展示模式可复制性。

### Q7: 技术栈为什么是 Node + EJS 而不是小程序？
- 当前是验证 PMF 的 Demo：EJS 轻量、单机可跑、迭代最快，重点是验证"测评→匹配→动线→校准"闭环的体验价值；小程序/H5 是已验证后的下一载体，前后端接口已按 API 化设计（/api/v1），迁移成本低。
