# 心旅 AI · 演示版需求清单（v1.0 初稿）

> 比赛/路演演示版 · 目标日期 **2026-10-17** · 基于 EJS v1.2 mainline
> 需求对齐会话产出（2026-08-12），词汇表见 `CONTEXT.md`，决策记录见 `docs/adr/0001~0003`

## 0. 演示目标

5 分钟内走完一条完整情感弧线：**快测 → 画像 → 人格卡 → 选城 → 动线 → 归途心灵足迹**。
视觉惊艳（全视觉沉浸），数据可信（精修场景），现场可兜底（降级路径）。

## 1. 演示节奏（6 屏）

| 序 | 屏 | 时长 | 要点 |
|----|----|------|------|
| 1 | 加载页 | 3-5s | 氛围入口，保留拼图动画 |
| 2 | 首页 | 15s | 项目介绍精简；**知情同意折叠进首页**（合规保留，不再单开一屏） |
| 3 | 测评页 | 60-90s | 全视觉沉浸（流体动效 + 氛围音），8 题情境快测 |
| 4 | 画像页 | 30s | 全视觉沉浸（惊喜点）：人格卡 + 四维雷达 + 出发前心灵指数 |
| 5 | 探索世界页 | 10s | 中国简化版图，景德镇开放可点，快速带过 |
| 6 | 城市路线页（动线） | 60s | 保持功能性，信息密度优先；拖拽/备选池为交互亮点 |
| 7 | 归途页 | 20s | **心灵足迹纪念卡**（新页面，压轴）：时间线 + 指数 + DeepSeek 札记 |

## 2. 页面级需求

- **测评页**：全视觉沉浸——背景随选择产生色彩渐变/涟漪，氛围音反馈；8 题框架与四维计分不动（matching.js 保持）
- **画像页**：全视觉沉浸——人格卡出现动效、四维雷达绘制动画、心灵指数滚动到 55-85
- **归途页（新）**：心灵足迹纪念卡 = 静态结构（行程时间线 + 出发前→归途指数）+ DeepSeek 生成"旅行心路札记"；去 Web3（无钱包/NFT 字样）
- **首页**：知情同意改为折叠区，项目介绍压缩到一屏内
- **动线页**：保持现状功能性，只做轻 polish（不加重动效）
- **探索世界页**：轻 polish，地图投影与开放城市交互保持

## 3. 数据精修（深度优先）

- 从现有 10 个景德镇真实场景精选 **6-8 个**，精修：诗意文案、营业时间、特殊活动、人流分布、导航链接
- 配图：当前场景仅有 emoji——需补视觉（AI 生成初版 + 筛选，或实拍）
- 目标：评委点开任意场景都挑不出毛病
- 演示环境数据隔离：演示前清空 `data/sessions/`，避免历史数据串场

## 4. 算法与叙事

- 匹配算法：演示版**保持 v1.2 matching.js 不动**（四维累加 → 6 人格）
- 评分叙事：心灵指数为主（出发前 55-85 → 归途校准至 98）；匹配度不进 UI
- 心理学模型（大五/荣格/美学向量）仅存在于 backend 引擎，作为赛后升级素材

## 5. 风险与待确认

| 项 | 风险 | 处理 |
|----|------|------|
| DeepSeek 文案 | key 配额/延迟/现场抽风 | 演示前实测；llm.js 已有降级文案路径，归途卡静态结构兜底 |
| 高德地图 | AMAP key 配额 | 演示前实测导航链接与地图组件 |
| 氛围音频 | 资源来源 | 免费音效库或合成；无音频时视觉动效独立成立 |
| 视觉动效 | EJS 无框架支撑 | CSS 动画 + 轻量 JS 实现，不引重依赖 |
| 场景配图 | 来源 | AI 生成初版 + 用户筛选（待确认） |

## 6. 里程碑（9 周）

- **8/13 - 9/7（3.5 周）核心改造**：首页合并、测评/画像/归途三页视觉沉浸、归途页开发
- **9/8 - 9/28（3 周）数据与内容**：场景精选精修、配图、文案、DeepSeek 札记调优
