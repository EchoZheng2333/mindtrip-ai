# 心旅 AI (MindTrip AI)

**GitHub 仓库地址：** https://github.com/EchoZheng2333/mindtrip-ai

---

## 项目简介

「心旅 AI」是一款将心理-美学算法测评与人文调性文旅场景深度匹配的定制化 AI 推荐系统。用户通过完成一份轻量级心理美学测试（约 5-8 分钟），系统解析其性格特质、审美偏好与情绪状态，再结合用户的旅行时间节点和预算，为其自动生成定制化的行程攻略。项目以景德镇为首发试点城市，覆盖非遗制瓷体验、独立陶瓷买手店、特色餐饮及隐秘景区等长尾商户资源。

## 项目方向与适用场景

**方向：** AI + 文旅推荐，聚焦"心理-美学"双维度的个性化行程规划。

**适用场景：**
- 深度游/定制游旅客，反感大众点评式"竞价排名"和碎片化攻略
- 景德镇、大理、阿那亚等具有强人文调性和独立商户集群的特色城市
- 非遗体验、手作工坊、独立买手店等长尾商户的精准流量分发

## 拟实现的核心功能

| 功能模块 | 说明 |
|---------|------|
| 灵魂美学测评 | 基于图像直觉选择、色彩情绪映射、场景心理投射等范式的轻量交互测试，输出用户的美学光谱与行为心理画像 |
| 心流日程生成 | 结合用户画像、时间节点、出行同伴与预算，AI 引擎在 3 秒内生成动态路径规划，每节点提供 3 选 1 备选 |
| 共鸣细节推荐语 | 每个推荐点附带 AI 生成的场景化推荐理由，描述店铺调性与用户画像的匹配逻辑 |
| 长尾商户入驻系统 | 商家自主完成调性标签标注（风格、氛围、适合人群），零门槛获取精准流量 |
